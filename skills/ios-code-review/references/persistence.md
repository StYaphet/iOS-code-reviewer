# 持久化审查清单（Core Data / 文件 / Keychain / Realm）

## 重点检查
- 线程安全：是否在正确队列/上下文读写。
- 数据一致性：写入失败或迁移失败的处理路径。
- 加密与隐私：敏感信息是否存储在 Keychain 或加密存储。
- 版本迁移：schema 变更是否有迁移策略。

## 常见问题提示
- 在主线程执行大量磁盘 IO。
- Core Data 上下文跨线程访问。
- 敏感信息明文存储在文件或 UserDefaults。

## 可执行建议模板
- “将大量读写移动到后台队列，并在完成后回主线程更新 UI。”
- “敏感信息应存储在 Keychain 或加密存储，并避免明文持久化。”
